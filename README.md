# My Tasks

설치나 로그인 없이 브라우저에서 바로 쓰는 개인용 할 일 관리 앱입니다.
하루 10~20개의 할 일을 **업무 / 개인 / 공부**로 나눠 관리하고, 진행률을 한눈에 확인할 수 있습니다.
HTML, CSS, 순수 JavaScript만으로 만들었고 외부 라이브러리나 빌드 도구가 필요 없습니다.

## 빠른 시작

`index.html`을 더블클릭해서 브라우저로 열면 끝입니다. 데이터는 브라우저의 localStorage에 자동으로 저장되므로 새로고침하거나 브라우저를 다시 열어도 그대로 남아 있습니다.

로컬 서버로 띄우고 싶다면:

```bash
python -m http.server 5174
```

그다음 브라우저에서 `http://localhost:5174`를 엽니다.

## 주요 기능

### 할 일 관리
- **추가**: 입력창에 쓰고 `Enter` 또는 [추가]를 누릅니다.
- **수정**: 할 일 글자를 더블클릭하거나, 키보드로 포커스한 뒤 `Enter`/`F2`를 누르면 인라인 편집이 열립니다. `Enter` 저장, `Esc` 취소이며 편집 중에 카테고리도 바꿀 수 있습니다.
- **완료 체크**: 체크박스를 누르면 취소선이 생기고 진행률에 바로 반영됩니다.
- **삭제**: ✕ 버튼으로 지우고, 완료한 항목은 [완료 항목 모두 삭제]로 한 번에 정리할 수 있습니다.
- **중복 확인**: 같은 내용의 할 일이 이미 있으면 경고하고 기존 항목을 깜빡여 보여 줍니다. 한 번 더 누르면 그래도 추가됩니다. 띄어쓰기와 대소문자 차이는 같은 내용으로 봅니다.
- **실행 취소**: 추가, 삭제, 체크, 수정, 순서 변경, 가져오기를 최대 30단계까지 되돌릴 수 있습니다. 알림의 [실행 취소] 버튼이나 `Ctrl+Z`를 쓰세요.

### 키워드 자동 분류
할 일을 입력하는 동안 키워드를 찾아 카테고리를 자동으로 골라 줍니다. 입력창 아래에 `🪄 '회의' → 업무`처럼 어떤 키워드로 분류했는지 표시됩니다.

| 입력 | 분류 | 근거 키워드 |
|---|---|---|
| 팀 회의 준비 | 업무 | 회의 |
| 주간 보고서 작성 | 업무 | 보고서 |
| 마트 장보기 | 개인 | 장보기 |
| 헬스 1시간 | 개인 | 헬스 |
| 토익 단어 50개 | 공부 | 토익, 단어 |
| Weekly Meeting | 업무 | meeting |

**분류 규칙**
- 할 일에 들어 있는 키워드의 글자 수를 카테고리별로 더해서 점수가 가장 높은 카테고리를 고릅니다. 긴 키워드일수록 더 구체적이라고 보기 때문입니다.
- 비교할 때 대소문자와 연속된 공백은 무시합니다.
- 점수가 같은 카테고리가 둘 이상이거나 맞는 키워드가 없으면 자동으로 바꾸지 않고 기본 카테고리를 씁니다.
- **직접 고른 카테고리가 항상 우선**합니다. 입력 중에 드롭다운을 직접 바꾸면 그 할 일에서는 자동 분류가 멈추고, 추가하거나 입력을 모두 지우면 다시 동작합니다.
- 입력창 아래의 [키워드로 카테고리 자동 분류] 체크박스로 끄고 켤 수 있고, 이 설정은 저장됩니다.
- 카테고리가 없는 예전 데이터나 가져온 파일도 불러올 때 같은 규칙으로 분류합니다.

**키워드 바꾸기**: `script.js` 위쪽의 `CATEGORY_KEYWORDS`를 수정하면 됩니다. 영어는 소문자로 적고, 한 글자 키워드는 다른 단어에 섞여 잘못 분류되기 쉬우니 피하세요(예: '책'은 '책상'에도 들어 있음).

```js
const CATEGORY_KEYWORDS = {
  work: ['업무', '회의', '보고서', /* ... */],
  personal: ['장보기', '운동', '병원', /* ... */],
  study: ['공부', '강의', '시험', /* ... */],
};
```

### 보기 · 정렬 · 검색
- **필터**: 전체 / 업무 / 개인 / 공부. 선택한 필터는 저장되고, 카테고리 필터를 보는 동안에는 새 할 일의 기본 카테고리도 그 카테고리가 됩니다.
- **검색**: 입력하는 대로 걸러지고 일치하는 부분이 강조됩니다. `Esc`로 지웁니다.
- **정렬**
  - 완료 상태순(기본): 미완료 항목이 위, 완료 항목이 아래
  - 최신순 / 오래된순
  - 카테고리순: 업무 → 개인 → 공부
  - 직접 정렬: 손잡이(⋮⋮)를 드래그하거나, 손잡이에 포커스한 뒤 `↑`/`↓`로 옮깁니다. 마우스와 터치 모두 되고, 드래그 중 `Esc`로 취소할 수 있습니다.

### 진행 현황
- 전체 진행률 막대, 카테고리별 미니 진행률, 오늘 추가한 개수
- 제목 옆의 남은 할 일 배지. 브라우저 탭 제목에도 `(3) My Tasks`처럼 표시됩니다.
- 진행률에 따라 바뀌는 응원 메시지와 매일 바뀌는 격언

### 백업
- **내보내기**: 모든 할 일을 `my-tasks-YYYY-MM-DD.json` 파일로 저장합니다.
- **가져오기**: JSON 파일을 고르면 파일 안의 할 일 개수, 백업 날짜, 제외될 항목을 보여 주고 방식을 묻습니다.
  - 합치기: 기존 목록에 새 항목만 더합니다(같은 id나 같은 내용은 건너뜀).
  - 덮어쓰기: 기존 목록을 파일 내용으로 바꿉니다.
  - 가져오기 전에 현재 데이터를 백업 파일로 먼저 저장하는 옵션이 기본으로 켜져 있습니다.
- 마지막 백업 날짜가 표시되고, 7일이 지나면 새로 백업하라고 알려 줍니다.

### 다크 모드
오른쪽 위 스위치 또는 `Alt+D`로 바꿉니다. 저장된 설정이 없으면 운영체제 설정을 따릅니다.

## 키보드 단축키

| 단축키 | 동작 |
|---|---|
| `Alt` + `N` | 할 일 입력창으로 이동 |
| `Alt` + `1` ~ `4` | 전체 / 업무 / 개인 / 공부 필터 |
| `Alt` + `D` | 다크 모드 켜기/끄기 |
| `Ctrl` + `Z` (Mac은 `Cmd` + `Z`) | 실행 취소 (입력창 밖에서) |
| `Enter` / `F2` | 포커스한 할 일 수정 |
| `Esc` | 수정 취소, 검색 지우기, 드래그 취소 |
| `↑` / `↓` | 직접 정렬에서 손잡이에 포커스한 할 일 이동 |

단축키는 한글 자판 상태에서도 동작합니다.

## 데이터

### localStorage 키

| 키 | 내용 |
|---|---|
| `myTasks` | 할 일 목록 (JSON 배열) |
| `myTasksFilter` | 선택한 필터 |
| `myTasksSort` | 정렬 방식 |
| `myTasksTheme` | `light` 또는 `dark` |
| `myTasksAutoCategory` | 자동 분류 사용 여부 (`on` / `off`) |
| `myTasksLastBackup` | 마지막으로 내보낸 시각 |

### 할 일 형식

```json
{
  "id": "mg1k2x3abc12",
  "text": "주간 보고서 작성",
  "category": "work",
  "completed": false,
  "createdAt": 1790000000000
}
```

`category`는 `work`, `personal`, `study` 중 하나입니다. 저장된 데이터나 가져온 파일은 불러올 때 모두 검증합니다. 내용이 비었거나 형식이 맞지 않는 항목은 제외하고, 글자 수는 100자로 자르고, 겹치는 id는 새로 만듭니다.

### 백업 파일 형식

```json
{
  "app": "my-tasks",
  "version": 1,
  "exportedAt": "2026-09-27T08:00:00.000Z",
  "count": 12,
  "todos": [ /* 할 일 형식의 배열 */ ]
}
```

가져오기는 위 형식과 할 일 배열만 있는 파일을 모두 받으며, 파일 크기는 5MB까지입니다.

## 파일 구조

```
my-tasks/
├── index.html   # 화면 구조, 테마 깜빡임 방지 스크립트
├── style.css    # 색상 변수(라이트/다크), 레이아웃, 애니메이션, 모바일 대응
├── script.js    # 상태, 저장, 렌더링, 이벤트
└── README.md
```

## 구현 메모

- **변경 흐름**: 모든 변경은 `commit()`을 거칩니다(상태 변경 → 저장 예약 → 다시 그리기). 실행 취소는 변경 직전의 목록을 복사해 쌓는 방식입니다.
- **효율적인 렌더링**: 할 일마다 DOM 요소를 id로 캐시하고, 내용이 바뀐 항목만 새로 만듭니다. 순서는 최장 증가 부분 수열(LIS)로 이미 제자리에 있는 노드를 남기고 필요한 노드만 옮깁니다. 500개 기준으로 체크 한 번에 약 7ms, DOM 삽입 1건입니다.
- **디바운싱**: 검색은 입력이 0.2초 멈춘 뒤, 저장은 마지막 변경 후 0.3초 뒤에 한 번만 처리합니다. 페이지를 닫거나 숨길 때는 바로 저장합니다.
- **애니메이션**: 추가/삭제 페이드, 위치가 바뀔 때 미끄러지는 FLIP 애니메이션. 보이는 항목이 150개를 넘으면 위치 애니메이션을 생략하고, 운영체제의 "동작 줄이기" 설정을 따릅니다.
- **보안**: 사용자 입력은 모두 `textContent`와 텍스트 노드로만 출력하고 `innerHTML`을 쓰지 않습니다.

## 접근성

- 모든 버튼과 입력 요소에 스크린 리더용 이름(`aria-label`)이 있습니다.
- 추가, 삭제, 필터 변경, 검색 결과 수, 순서 이동을 `aria-live` 영역으로 알려 줍니다.
- 키보드로 삭제하면 다음 항목으로, 수정을 마치면 그 할 일로 포커스가 돌아옵니다. 체크로 항목이 이동해도 포커스가 따라갑니다.
- "할 일 입력으로 건너뛰기" 링크, 진행률 막대의 `aria-valuetext`, 다크 모드 스위치의 `role="switch"`를 제공합니다.

## 지원 환경

최신 Chrome, Edge, Safari, Firefox에서 동작합니다. 360px 폭의 모바일 화면부터 데스크톱까지 대응합니다.

## 알아 둘 점

- 데이터는 **브라우저마다 따로** 저장됩니다. 크롬에서 입력한 할 일은 엣지에서 보이지 않습니다. 다른 브라우저나 기기로 옮기려면 내보내기/가져오기를 쓰세요.
- 브라우저의 사이트 데이터를 지우면 할 일도 사라집니다. 주기적으로 내보내기로 백업해 두세요.
- 시크릿 모드에서는 창을 닫으면 데이터가 사라집니다.
- 크롬과 엣지는 원래 `Alt+D`를 주소창 이동에 씁니다. 앱이 이 동작을 막도록 되어 있지만, 브라우저 설정에 따라 주소창으로 이동할 수 있습니다.
